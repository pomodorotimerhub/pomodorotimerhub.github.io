# Pomodoro Timer

Focus in 25-minute Pomodoro sessions with short and long breaks. Free online timer with a session counter and task list.

Free online tool site built for GitHub Pages. Static HTML, CSS and JavaScript only — no build step, no server, no tracking. Open `index.html` to start.

- Main tool: Pomodoro Timer (`tools/pomodoro-timer.html`)
- 4 tools, 20 guides, 20 images.
